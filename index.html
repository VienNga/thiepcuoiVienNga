🚀 Xuất bản thiệp lên web (GitHub Pages) Chưa xuất bản

Mỗi thiệp được xuất bản vào một thư mục riêng, có link riêng để gửi khách. Bấm Xuất bản lần nữa mỗi khi bạn sửa thiệp để cập nhật link đó.

⚙️ Cài đặt kết nối GitHub (làm một lần)

Tạo token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Chọn Only select repositories và chỉ chọn repo này; ở Repository permissions đặt Contents: Read and write. Token chỉ lưu trong trình duyệt của bạn, không đi vào thiệp gửi khách.

Chia sẻ cho khách & Tạo link tên khách mời

🌐 Link cho khách: là link thiệp đã xuất bản (bấm "🚀 Xuất bản thiệp này" ở trên trước). Thêm ?guest=Tên Khách để cá nhân hóa tên khách mời.
